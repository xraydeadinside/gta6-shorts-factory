# Фабрика YouTube Shorts по GTA 6

Бесплатно, без сервера на ноутбуке.

```
Телефон (Telegram-бот)  ─┐                         ┌─> GitHub Actions (бесплатно, публичный репо)
Ноутбук (веб-панель)    ─┼─> Cloudflare Worker ────┤    скачать → найти вебку → речь в текст →
                         │   отвечает за 1–2 сек,   │    Gemini монтирует → ffmpeg 9:16 → видео в Telegram
                         │   хранит всё в D1        <┘    и результат обратно в Worker
```

## Как пользоваться

| В боте | Что будет |
|---|---|
| `/clip ссылка` или просто ссылка | монтаж момента: клип Twitch, VOD с `?t=1h2m3s`, YouTube с таймкодом |
| `/vod ссылка` | лучшие моменты записи Twitch по всплескам чата (по умолчанию 3 шортса) |
| `/status` | что в работе |
| `/login` | одноразовая ссылка на веб-панель |

Под каждым шортсом есть кнопки:
- 1/2/3: выбрать одно из трёх названий;
- новые названия, своё название, своё описание;
- «Перемонтировать»: пиши пожелание своими словами;
- промпт для Google Flow: утвердить, другой, пожелание. Готовое видео из Flow пришли **ответом** на сообщение с промптом, и оно встанет интро;
- «Опубликовать»: бот пришлёт название, описание и теги, их можно скопировать нажатием;
- «Отклонить».

## Монтаж
- **Части момента.** Gemini делит клип на части: хук → завязка → панчлайн → реакция → развязка. Скучное выкидывает и объясняет монтаж по-русски.
- **Раскладка 9:16.** Вебка сверху, игра снизу. Вебку движок находит сам: ищет лицо, которое стоит на месте, и неподвижную рамку. В игровой части вебка замазана, чтобы не было двойного лица.
- **Виртуальная камера.** Наезд, проезд, рывок и медленный дрейф с плавным ускорением. На реакциях короткий крупный план лица.
- **Текст на экране.** Субтитры по 1–2 слова, панчлайн выделен цветом. Огромный заголовок первые 3 секунды, он стоит под вебкой и не закрывает лицо. Всплывающие выкрики.
- **Звук.** Синтезированный «вжух» на склейках (без авторских прав), громкость −14 LUFS, без музыки, чтобы не делить доход с правообладателями.
- **Прочее.** Прогресс-бар, подпись twitch.tv/стример. Файл до 19 МБ, чтобы Telegram и панель могли его отдать.
- **Правила YouTube Shorts.** Хук в первые 1–3 сек, смена кадра каждые ≤3 сек. Название 4–6 слов, «GTA 6» в первых 40 символах. В описании главное в первых 125 символах, 3–5 хэштегов, 10–15 тегов.

Стиль (цвета, сила наездов, длина, размер субтитров…) меняется в панели: кнопка ⚙️ «Стиль».

## Что выключено и как включить
- **Автопоиск клипов через Twitch API:** см. [`engine/twitch_auto.py`](engine/twitch_auto.py).
- **Автозагрузка на YouTube:** см. [`engine/youtube_upload.py`](engine/youtube_upload.py), затем галочка в настройках панели.

## Где лежат ключи
Только в GitHub Secrets, Cloudflare secrets и локальном `.env` (он в `.gitignore`). В коде ключей нет.

## Устройство репозитория
- `engine/`: монтаж на Python (запускается в GitHub Actions). Тесты в `tests/`.
- `worker/`: бот и панель на Cloudflare Workers + D1. Тесты в `worker/test/`.
- `.github/workflows/`: `render.yml` (монтаж), `tests.yml` (тесты), `twitch-auto.yml` (выключен).
